# Mahrus React Portfolio

A fresh React project for my personal portfolio, created with Vite and JavaScript.

## Run locally

Install a current Node.js LTS release, then run:

```sh
npm install
npm run dev
```

Open the local URL printed in the terminal.

## Check and build

```sh
npm run lint
npm run build
npm run preview
```

## Project structure

- `src/App.jsx`: main React component
- `src/App.css`: component styles
- `src/index.css`: global styles
- `src/main.jsx`: React entry point
- `public/`: static assets

## Portfolio plan

The portfolio will use a dark theme with a navbar, hero, about section, reusable project cards, skills, and contact links. This repository currently contains the base React starter; the portfolio design will be implemented next.
